# 🎵 Партитура дня

Личный трекер дня: работа, здоровье, спорт, музыка, французский язык и питание — в одном месте. Работает с телефона и компьютера, данные хранятся в облаке (MongoDB Atlas) и переживают перезапуски сервера.

## Возможности

- **Сегодня** — утро и сон, спорт (приседания, турник, брусья с подходами), музыка, питание (завтрак/обед/ужин), вечер с алкоголем и счётчиком дней трезвости. Каждый раздел сохраняется независимо.
- **Дата** — можно редактировать любой день задним числом: клик по дате в шапке открывает календарь, стрелки листают дни вперёд/назад.
- **Работа** — учёт откликов на вакансии со статусами и график динамики по дням.
- **Французский** — генерация текстов для чтения (A1–B2) по теме через Claude API, кликабельные слова с переводом, транскрипцией и разбором грамматики (включая таблицы спряжений), личный словарь с поиском и сортировкой. Разобранные слова кэшируются — повторный клик не тратит новый запрос к AI.
- **История** — сводка по последним дням.
- **Графики** — сон, работа, спорт, музыка, алкоголь в динамике за 14/30/90 дней.

## Технологии

- **Backend:** Node.js + Express
- **База данных:** MongoDB Atlas (с автоматическим fallback на локальный `db.json`, если `MONGODB_URI` не задан)
- **Frontend:** чистый HTML/CSS/JS, без сборки — один файл `public/index.html`
- **Графики:** Chart.js
- **AI:** Anthropic Claude API — генерация текстов для чтения и разбор слов

## Структура проекта

```
day-tracker-server/
├── server.js          # Express-сервер и все API-эндпоинты
├── package.json
├── public/
│   └── index.html     # весь фронтенд одним файлом
├── config.json         # локальный API-ключ (не в git)
└── db.json             # локальная база данных (не в git, только для оффлайн-режима)
```

## Запуск локально

```bash
npm install
```

Создайте `config.json` рядом с `server.js`:

```json
{ "anthropicApiKey": "sk-ant-..." }
```

Запуск:

```bash
npm start
```

Сайт откроется на `http://localhost:10000`.

## Переменные окружения (для облачного деплоя)

| Переменная | Назначение |
|---|---|
| `ANTHROPIC_API_KEY` | ключ для генерации текстов и разбора слов |
| `MONGODB_URI` | строка подключения к MongoDB Atlas — если не задана, сервер работает на локальном файле `db.json` |

## Деплой

Проект развёрнут на [Render](https://render.com) с автодеплоем при каждом push в ветку `main`. База данных — MongoDB Atlas (бесплатный тариф M0).

## Заметки для себя

- API-ключ и строка подключения к базе — только в переменных окружения на Render, никогда не в коде и не в этом файле.
- `config.json` и `db.json` в `.gitignore` — не коммитятся.
